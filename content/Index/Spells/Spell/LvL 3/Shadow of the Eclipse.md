| Shadow of the Eclipse  |
| ---------------------- |
| level 3 spell          |
| Casting Time: 1 action |
| **Components:** V, S   |
| duration : 1min        |
| Range: 60 ft           |

You curse a creature with the eclipse’s shadow.
Target makes a WIS save. On fail:
At the start of each of its turns, roll 2d6 
on a Even roll: it takes radiant damage.
on a Uneven roll: it takes necrotic damage.
While cursed, the creature cant see further then 20ft
makes a Wisdom save at the end of its turn
